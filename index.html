02 / PHYSICAL COMPONENTS

Inside the Hardware

Hardware adalah seluruh komponen fisik pada sistem komputer. Komponen ini menerima input, memproses data, menyimpan data, dan menghasilkan output.

HARDWARE / PHYSICAL LAYER
DEFINITION

Apa itu Hardware?

Hardware adalah perangkat keras berupa komponen elektronik, mekanik, atau elektromekanik yang membentuk sebuah sistem komputer.

Hardware membutuhkan instruksi dari software agar dapat menjalankan tugas tertentu. Namun, beberapa perangkat juga memiliki firmware, yaitu perangkat lunak tingkat rendah yang membantu mengendalikan perangkat keras.

Contoh sederhana

Keyboard mengirimkan input, CPU memproses instruksi, RAM menyimpan data sementara, dan monitor menampilkan hasil.

COMPONENT DATABASE

Kenali Perangkat Keras

Pilih kategori untuk mempelajari fungsi dan contoh komponennya.

01
PROCESSING

CPU / Processor

Menjalankan instruksi dan melakukan operasi aritmetika serta logika. CPU sering disebut pusat pemrosesan komputer.

Contoh: Intel Core, AMD Ryzen
02
MEMORY

RAM

Menyimpan sementara data dan instruksi yang sedang digunakan. Isinya umumnya hilang ketika daya mati.

Contoh: DDR4, DDR5
03
MAIN BOARD

Motherboard

Papan utama yang menghubungkan CPU, RAM, penyimpanan, dan berbagai komponen lainnya.

Contoh: motherboard ATX, Micro-ATX
04
GRAPHICS

GPU / VGA

Memproses grafis dan menghasilkan data gambar untuk ditampilkan. GPU juga dapat membantu komputasi tertentu.

Contoh: GPU terintegrasi dan diskret
05
STORAGE

SSD / HDD

Menyimpan sistem operasi, aplikasi, dan file secara jangka panjang. SSD memakai memori flash, sedangkan HDD menggunakan piringan magnetik.

Contoh: SSD SATA, SSD NVMe, HDD
06
POWER

Power Supply (PSU)

Mengubah listrik AC dari sumber listrik menjadi tegangan DC yang dibutuhkan komponen komputer.

Perhatikan daya dan konektor yang sesuai.
07
INPUT

Keyboard

Memasukkan huruf, angka, simbol, dan perintah melalui tombol-tombolnya.

Jenis: membran dan mekanis
08
INPUT

Mouse

Mengendalikan penunjuk di layar untuk memilih, mengeklik, menyeret, dan menjalankan perintah.

Jenis: kabel dan nirkabel
09
OUTPUT

Monitor

Menampilkan informasi visual berupa teks, gambar, antarmuka, dan video.

Contoh: LCD, LED, OLED
10
OUTPUT

Printer

Menghasilkan salinan fisik dokumen atau gambar pada kertas maupun media tertentu.

Contoh: inkjet dan laser
11
NETWORK

NIC / Network Card

Menyediakan antarmuka agar komputer dapat terhubung ke jaringan melalui Ethernet atau Wi-Fi.

Contoh: Ethernet adapter, Wi-Fi adapter
12
AUDIO OUTPUT

Speaker

Mengubah sinyal audio menjadi suara yang dapat didengar oleh pengguna.

Contoh: speaker aktif dan speaker USB

Catatan: gambar berasal dari layanan eksternal dan memerlukan koneksi internet. Nama model pada contoh hanya ilustrasi, bukan rekomendasi produk tertentu.

03 / DIGITAL INSTRUCTIONS

Discover Software

Software membuat komputer mampu menjalankan instruksi, mengelola perangkat keras, dan membantu pengguna bekerja.

SOFTWARE / LOGICAL LAYER
DEFINITION

Apa itu Software?

Software adalah kumpulan program, prosedur, dan instruksi yang digunakan untuk mengatur operasi komputer atau menyelesaikan tugas tertentu.

Software tidak berbentuk fisik seperti keyboard atau RAM. Software disimpan sebagai data digital dan dijalankan oleh sistem komputer.

Contoh sederhana

Windows mengelola sistem komputer, browser membuka situs web, dan Visual Studio Code membantu menulis kode program.

SOFTWARE CATEGORIES

Jenis-Jenis Software

04 / SIDE BY SIDE

Hardware vs Software

Keduanya berbeda, tetapi saling membutuhkan untuk menjalankan sistem komputer.

Aspek Hardware Software
Wujud Komponen fisik Program dan instruksi digital
Dapat disentuh? Ya, sebagai perangkat fisik Tidak secara fisik
Fungsi Menerima, memproses, menyimpan, atau menghasilkan data Memberikan instruksi dan layanan kepada sistem atau pengguna
Contoh CPU, RAM, monitor, keyboard Windows, Linux, browser, aplikasi
Kerusakan Bisa aus atau mengalami kerusakan fisik Bisa mengalami bug, korupsi data, atau kesalahan konfigurasi
Perawatan Pembersihan, pemeriksaan koneksi, dan penggantian komponen Pembaruan, pencadangan, pemeriksaan keamanan, dan perbaikan program

06 / QUICK REFERENCE

Mini Glossary

Istilah penting yang sering ditemui saat belajar TKJ.

CPU

Central Processing Unit, komponen utama untuk menjalankan instruksi.

RAM

Random Access Memory, tempat penyimpanan data sementara saat komputer bekerja.

ROM

Read-Only Memory, istilah memori yang menyimpan data atau instruksi nonvolatil; implementasi modern bervariasi.

OS

Operating System, software dasar yang mengelola sumber daya komputer.

GUI

Graphical User Interface, antarmuka berbasis elemen visual.

CLI

Command-Line Interface, antarmuka yang menerima perintah berbentuk teks.

Driver

Software yang membantu sistem operasi berkomunikasi dengan perangkat tertentu.

BIOS / UEFI

Firmware yang membantu menginisialisasi hardware dan memulai proses booting.
